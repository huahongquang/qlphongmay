Cách tạo Webhook Drive (2 phút):

  2. Truy cập script.google.com ➡️ Dự án mới ➡️ Dán code đã sao chép.
  3. Bấm Triển khai (Deploy) ➡️ Ứng dụng web ➡️ Ai có liên kết đều truy cập được ➡️ Dán URL Webhook vào ô trên.
